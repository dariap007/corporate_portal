# Корпоративный портал "Три Точки"

Веб-приложение разработано как MVP для производственной практики ПП.01.

Тема проекта: **"Разработка веб-корпоративного портала для сотрудников группы компаний Три Точки"**.

Проект сделан на Python и Django. Он запускается локально на компьютере и использует бесплатные инструменты: Django, SQLite, HTML, CSS и Bootstrap 5 через CDN.

## Цель проекта

Цель проекта - создать простой корпоративный портал для сотрудников компании, который показывает основные рабочие сценарии:

- вход в систему;
- просмотр главной страницы портала;
- просмотр новостей компании;
- поиск сотрудников;
- просмотр документов и базы знаний;
- создание внутренних заявок;
- просмотр статусов заявок;
- просмотр и частичное редактирование личного профиля;
- базовое управление данными администратором через интерфейс сайта.

## Основные роли

В проекте реализованы две роли.

**Сотрудник** может:

- входить в личный аккаунт;
- просматривать новости;
- искать сотрудников;
- открывать карточки сотрудников;
- просматривать документы;
- создавать заявки;
- видеть только свои заявки;
- смотреть комментарии администратора к заявкам;
- редактировать только телефон и дополнительные контакты в профиле.

**Администратор** может:

- видеть все заявки сотрудников;
- менять статус заявки;
- добавлять комментарий администратора к заявке;
- создавать, редактировать и удалять новости;
- создавать, редактировать и удалять сотрудников;
- управлять подразделениями;
- создавать, редактировать и удалять документы;
- управлять быстрыми ссылками на корпоративные сервисы.

## Как запустить проект с нуля на Windows

Инструкция подходит для запуска в терминале PyCharm или PowerShell.

### 1. Установить Python

Проверьте, что Python установлен:

```powershell
python --version
```

Пример корректного результата:

```text
Python 3.13.7
```

Если команда не работает, нужно установить Python с официального сайта и при установке включить галочку **Add Python to PATH**.

### 2. Скачать проект

Если проект находится на GitHub, его можно скачать через кнопку **Code -> Download ZIP** или склонировать командой:

```powershell
git clone https://github.com/USERNAME/corporate_portal.git
```

После этого нужно перейти в папку проекта:

```powershell
cd corporate_portal
```

Если проект уже открыт в PyCharm, достаточно открыть терминал в корневой папке, где находится файл `manage.py`.

### 3. Создать виртуальное окружение

```powershell
python -m venv venv
```

Виртуальное окружение нужно, чтобы зависимости проекта хранились отдельно от глобального Python.

### 4. Активировать виртуальное окружение

```powershell
venv\Scripts\activate
```

После активации в начале строки терминала обычно появляется:

```text
(venv)
```

Если PowerShell запрещает запуск скриптов, можно выполнить:

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

После этого нужно закрыть и заново открыть терминал, затем снова выполнить:

```powershell
venv\Scripts\activate
```

### 5. Установить Django

```powershell
pip install django
```

Проверить установку Django:

```powershell
python -m django --version
```

### 6. Создать миграции, если их нет

В проекте уже есть миграции, но если запускается новая версия проекта, можно выполнить:

```powershell
python manage.py makemigrations
```

### 7. Применить миграции

```powershell
python manage.py migrate
```

Эта команда создаёт таблицы базы данных SQLite.

### 8. Заполнить базу тестовыми данными

```powershell
python manage.py seed_data
```

Команда создаёт:

- подразделения;
- сотрудников;
- тестовые аккаунты;
- новости;
- документы;
- ссылки на сервисы;
- заявки.

Команду можно запускать повторно. Она обновляет тестовые данные и не должна создавать лишние дубли.

### 9. Запустить сайт

```powershell
python manage.py runserver
```

После запуска в терминале появится адрес:

```text
http://127.0.0.1:8000/
```

Откройте этот адрес в браузере.

### 10. Войти в систему

Откройте страницу:

```text
http://127.0.0.1:8000/login/
```

Войдите под одним из тестовых аккаунтов:

```text
admin / admin12345
employee / employee12345
```

## Быстрый запуск, если проект уже настроен

Если виртуальное окружение уже создано и Django установлен, достаточно выполнить:

```powershell

python manage.py migrate

```

Затем открыть:


## Возможные ошибки и решение

### Ошибка: `python` не является внутренней или внешней командой

Python не добавлен в PATH. Нужно переустановить Python и включить галочку **Add Python to PATH**.

### Ошибка при активации `venv`

Если PowerShell запрещает запуск скриптов, выполните:

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

Потом заново откройте терминал.

### Ошибка: `No module named django`

Django не установлен в активном виртуальном окружении. Выполните:

```powershell
venv\Scripts\activate
pip install django
```

### Ошибка: `no such table`

Не применены миграции. Выполните:

```powershell
python manage.py migrate
```

### Не получается войти под тестовым пользователем

Скорее всего, не выполнена команда заполнения тестовыми данными:

```powershell
python manage.py seed_data
```

### Сайт не открывается

Проверьте, что сервер запущен:

```powershell
python manage.py runserver
```

И откройте именно этот адрес:

```text
http://127.0.0.1:8000/
```

## Примечание про localhost

При локальном запуске сайт открывается по адресу `127.0.0.1:8000` или `localhost:8000`, потому что он работает только на компьютере разработчика.

Чтобы сайт открывался как обычный публичный сайт в интернете, его нужно разместить на хостинге, например PythonAnywhere, Render или другом сервере. Для учебного MVP локального запуска достаточно.
